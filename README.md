# Action75 Wallpaper

把 Action75 的键盘副屏变成一张会回应按键的壁纸。按下一个键，恒星、裂纹或烟花就从对应的位置出现。

## 首次连接

**系统要求**　64 位 Windows 10（版本 2004 或更高）或 Windows 11。请从发行页的 **Assets** 下载安装包，运行后接好键盘。

1. 使用普通副屏时，按 **Win + P** 选择 **「扩展」**。Windows 已将键盘屏识别为 HMD 时，软件会显示「Action75 HMD」。
2. 启动软件，在「连接 Action75」中选择键盘上的屏幕。它的分辨率是 **1920 × 720**，符合条件的副屏会显示为「键盘屏候选」。如果列表为空，检查投影模式和连接线，再点「刷新设备」。
3. 在「键盘输入」中选中 **Action75**，点击「开始使用」。打开壁纸库，选择一款壁纸，按键查看效果。

<img src="docs/images/setup.jpg" width="476" alt="首次连接窗口，依次列出扩展模式提示、刷新设备、候选屏幕和键盘输入">

> [!IMPORTANT]
> **选错屏幕时如何退出**  
> 开启「键盘副屏专用」后，鼠标将无法进入选中的副屏。如果误选了普通显示器，该屏幕可能无法用鼠标操作。按 **Ctrl + Alt + Shift + Q** 可完全退出软件、停止壁纸并释放鼠标。下次打开时到「设备与输出」重新选择。

在壁纸库中单击缩略图即可切换。按住卡片拖动时，半透明缩略图会跟随鼠标。将它拖到目标卡片左侧或右侧，看到插入线后松手即可排序，重启后仍保留顺序。

右侧设置随壁纸变化。例如，「黑洞」可以分别调整黑洞和恒星；「水波」可以分别调整涟漪和水底背景。展开对应的「高级设置」可微调效果。

## 使用壁纸

本机图片或视频可以从「导入 → 视频或图片」直接添加，随后在右侧调整亮度、色相、饱和度、缩放和位置。视频使用 Windows 解码器并静音循环播放。

互动壁纸支持分别调整背景和前景或主体的不透明度。背景设为 0%、前景保留 100%，即可在键盘屏原有的桌面壁纸上显示按键特效。

### 导入别人制作的壁纸

1. 打开 [Action75 壁纸仓库](https://github.com/blackwhite-poi/Action75-Wallpaper-Library)。选择喜欢的壁纸，下载对应的中文 ZIP 压缩包。
2. 在「壁纸库」点击 **导入 → ZIP 压缩包**，选择刚下载的文件。已解压的作品可通过「导入 → 壁纸文件夹」选择含 `manifest.json` 的目录。
3. 导入完成后，点击新壁纸的缩略图。控制台会显示这个包提供的参数。右键缩略图可以打开对应的壁纸文件夹或删除壁纸。

原生壁纸包可以包含可执行的 DLL，请从信任的作者处获取。

### 后台播放与更新

- **后台播放**：关闭控制面板后，壁纸会继续播放。右键系统托盘图标可以暂停播放、设置开机运行或完全退出。
- **资源占用**：打开「性能监控」查看播放器的运行情况。比较不同壁纸时，请保持分辨率和触发频率一致。
- **软件更新**：安装版打开控制台时会检查更新，持续打开时每 24 小时复查一次。也可以在「设置」中手动检查。有新版时点「立即更新」。安装期间会短暂停播，完成后恢复之前的壁纸和设置。

## 常见问题

换接口、重新插拔键盘或调整显示器后，打开「设备与输出」，点击「刷新设备」。软件会按分辨率标记候选副屏。多个副屏分辨率相同时，请核对实际连接的屏幕。选择其他分辨率的副屏时，软件会提醒风险，确认后仍可使用。主屏无法选作键盘屏。

| 遇到的情况 | 处理方法 |
| --- | --- |
| 找不到键盘屏候选 | 先到 Windows 显示设置确认副屏已被识别，再按 Win + P 选择「扩展」，回到软件刷新设备。 |
| 壁纸在播放，但按键没有特效 | 在「设备与输出 → 键盘输入」中选中 Action75，再按键测试。 |
| 特效位置偏离实际键位 | 打开「键位校准」，预览拟合后的键位，确认位置后保存。 |
| 只有在游戏中看不到按键特效 | 在「设备与输出」尝试开启「管理员游戏兼容」。 |

## 制作并接入自己的壁纸

一款壁纸就是一个文件夹。播放器把键位坐标和输入事件交给作品，控制台根据包里的参数声明生成面板。做一段按键动画可以只画图；做需要持续记住状态的角色或小游戏，可以自己写输入逻辑与着色器。

| 你想做什么 | 作者需要准备什么 |
| --- | --- |
| 按键时播放一段手绘动画 | 一张透明 PNG 图集、一张背景图，以及格数、时长等[图集参数](skills/action75-wallpaper-author/references/pack.md)。 |
| 让粒子散开、下落或拖出尾迹 | 用 Effekseer 制作兼容的 CPU 粒子，随包放入效果文件和素材。多个变体可配置[播放顺序和触发间隔](skills/action75-wallpaper-author/references/playback.md)。 |
| 制作磁流体、角色互动或小游戏 | 用 C++ 和 D3D11 或 D3D12 实现自己的状态、输入与绘制，编译为 Windows x64 DLL。[原生接口与生命周期](skills/action75-wallpaper-author/references/native.md) |

### 跟做一款「薄荷光环」

取得本仓库（页面上方 **Code → Download ZIP**），解压后进入 `skills/action75-wallpaper-author`。在此目录打开 PowerShell，用已安装的 Python 3 运行：

```powershell
python -m pip install Pillow
python scripts/create_ring.py ./mint-ring --id mint-ring --name "薄荷光环"
```

在控制台选择 **壁纸库 → 导入 → 壁纸文件夹 → mint-ring**，点击新壁纸，再按一个键。青色光环会从键位向外展开。下图是 0.3.8 播放器加载这份示例后的实际画面。

![薄荷光环示例的按键触发画面](docs/images/mint-ring.jpg)

想换动画，编辑成品中的 `ring.png`；想换底色或底图，编辑 `base.png`；想调整面板，编辑 `settings.json`。`manifest.json` 把这些文件关联起来。把整个 `mint-ring` 文件夹交给其他用户，他们就可以通过同一个入口导入。

### 用作者 Skill 协作制作

把 [作者 Skill](skills/action75-wallpaper-author/SKILL.md) 所在的整个文件夹交给开发助手，保留其中的参考文档、脚本和素材。告诉它安装目录、想看到的动作，以及希望用户能调哪些参数。例如：

> 请按这个 Skill 做一款按键光环壁纸。光环从按下的键位向外扩散，背景保持静止。允许分别调整光环的亮度和大小。请交付可直接导入的文件夹，并用播放器截一张触发后的图。

[从生成到试播](skills/action75-wallpaper-author/references/workshop.md) 给出了离屏验证命令，可以固定按键和采样时间，对比参数变化。按[参数分组规范](skills/action75-wallpaper-author/references/pack.md#参数分组)组织面板：亮度、色相和颜色放在所属对象的基础设置，运动与交互放在高级设置。交付前，将成品复制到一个新目录，重新导入，检查按键位置、参数效果和重新加载后的表现。
